This directory holds trained model artifacts generated by `python train.py`.

Files generated here:
  - congestion_model.joblib   (sklearn Pipeline: StandardScaler + XGBoost)
  - label_encoder.joblib      (LabelEncoder mapping class index → class name)
  - confusion_matrix.png      (Evaluation plot saved during training)

All of these are git-ignored. Run `python train.py` from ml-engine/ to generate them.
